## 四、图层 id 的性质（**我们没有用它判身份**）

**PS 的图层 id 是全局唯一的**（跨文档不撞）——这是它的优点，改名不改 id、换图层 id 必变。

但**官方没有拿它判身份**：`r.eventData.layerID` 传给了 `ztSelectLayer`，而 `selectLayer`
**无参**、`zt_getFontSimpleInfo` 也不带参 —— 官方靠事件就够，不需要 key。

**我们也没有用**：我们的身份是「类型 + 图层名」（`useFontPanel.ts:90` / `layer-watcher.tsx:83`），
所以**改图层名会多读一次文字属性**（界面无变化）。**官方也一样** —— `slct` 的 `layerID` 分支里
`cyUpdataLayerName` 与 `ztSelectLayer` 并列，改名时它同样重读。

（我此前写「我们该用 id，因为它比类型 + 图层名可靠」—— 那是**从轮询实现倒推出来的伪问题**：
「改名多读一次」在官方那里同样存在，不是我们特有的缺陷。）

**别自己造 id**：`layer.id` 那类要额外处理「不同文档 id 重复」，得再加文档索引。
