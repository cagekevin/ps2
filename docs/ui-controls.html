四、交互原语（hooks/）

控件的行为都从这里取，不在组件里各写一份监听。带【范本】的是唯一写法。

hook作用关键约束
useDismiss点外部 / Esc 关闭浮层全项目唯一 document mousedown + keydown 监听；IconPanel 刻意不挂（点外不关）
useFloatingPosition浮层定位：算位置、夹取、可选翻转唯一锚点矩形入口；update() 返回锚点矩形，对齐宽度也用它
floating-position定位纯函数零 DOM 依赖，可单测
useFocusTrap模态弹窗 Tab 循环 + 关闭还原焦点只给模态用（InputDialog / Confirm）
useDraft输入框里的本地值（受控草稿）外部值变了才回填，渲染期收敛
usePersisted会记住的 state（界面偏好）走 core/prefs，key 强类型
useShortcut全局字母快捷键（导航切页）与 useDismiss 分工：它管常驻字母键，排除打字中与修饰键
useLongPressDrag300ms 长按拖拽 + 克隆占位 + 浮层跟手拖拽期间挂 .mm-drag-float 层级
usePagedList列表分片：每页 30 + 触底追加筛选变化回第一屏
useInfiniteScroll触底加载全项目唯一 IntersectionObserver
useRunCommand执行一条命令：包 loading + 失败提示 + 原因留痕code / detail 进日志，人话进 toast；页面不再各写一份
useToast提示条口模块级单例，不读 context
useLoading全屏加载口模块级单例；文案栈
input-method-enter输入法选词时的 Enter 判定（enterSubmit）判据 + preventDefault + 执行三件事一处
