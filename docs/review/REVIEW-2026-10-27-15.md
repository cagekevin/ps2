# 第十五次体检 · 字体 M3 标签导入导出（2026-10-27）

> 触发：`GOVERNANCE` §7.1 #1（完成一个功能）。
> 范围：标签/评分导入导出 + 任意路径读写。真机未跑。

---

## 一、链路

```
确认框（页面 useConfirm）
  → core/dialog.openFile / saveFile
  → core/storage.readTextAt / writeTextAtAtomic
  → domain/font-meta.parseTagArchive（导入前逐项校验）
  → repo/font-repo.replaceFontTags / replaceFontStars（整份覆盖，写前 .bak）
```

页面、命令、repo 各层没有越界：`features` 里没有 `window.cep.fs`、没有 `readFileSync`。

---

## 二、安全口径

| 约束 | 落地 |
|---|---|
| 校验不过一个字都不写 | `parseTagArchive` 先整份校验，失败直接返回 `CORRUPT` |
| 取消不写盘 | 确认框取消 → 不执行命令；文件对话框取消 → `CANCELLED`，不写 |
| 覆盖前留退路 | 标签/星级走 `writeTextAtomic`，原文进 `.bak` |
| 未知键不丢 | 导入项**原样返回**，不重建对象 |
| `star` 字符串/数字混用 | 校验接受两种，导出原样带走，不规范化 |
| 导出是新文件 | `writeTextAtAtomic` 不生成 `.bak`，同路径写仍串行 |
