### `IconPanel` 的机制改造（消除落后帧 + 补 aria）

改造前：面板节点存进 `panels.current`（ref），组末尾按 `openIds` 读 Map。`register` 写在
**无依赖的 `useEffect`** 里，不触发渲染 ⇒ 点击打开的那一帧读到的是上一轮注册的旧节点，
paint 后 effect 才写入且没人再读，**面板会停在旧内容直到下一次任意重渲染**。

改造后（`createPortal`）：

| 项 | 改前 | 改后 |
|---|---|---|
| 面板节点位置 | 组件外（ref → 组读 Map） | 仍在 `IconPanel` 的 React 子树里，portal 只搬 DOM |
| 内容更新 | 依赖「父级重渲染 → 组重渲染」 | props 变化即正常更新，无落后帧 |
| 注册机制 | `register` + `panels` Map + 无依赖 effect | 全删；只剩 `mount/unmount` 计数做 id 判重 |
| id 重复 | 静默「点 A 开 B」 | 挂载时 `log.warn`（同组计数 > 1） |
| 无障碍 | 默认触发器无 `aria-expanded` / `aria-controls` | `IconButton` 新增 `ariaExpanded` / `ariaControls`；自定义 `trigger` 的 handlers 也带 `aria-controls` |
| 收起时开销 | 每次渲染都调 `panel(close)` | 只在展开时调用 |
