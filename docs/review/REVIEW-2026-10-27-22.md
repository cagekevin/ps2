## 4. 本次体检的修复

1. **计数口径错**（会让人按错数抄）：`26 个 = v1 覆盖 11 个 jsx（12 条命令）+ 只登记 2 + v2 13`。

   `core/ps/common-use.ts:2`、`core/ps/init.ts:81`、`PS-CHANNEL-NOTES` §11.4 首句、
   `GOVERNANCE` 4.1 与 §八、计划 §3.1/§7.4 与签名块注释。
2. **`init.ts` 注释「文本属性 27 个」**：`zt_getTypeUnits` 取消后实际 26（3 读 + 23 写），已改。
3. **`CONVENTIONS` §3 目录树漂移**：缺 `core/prefs`、`core/clipboard`、`core/dialog`、`core/image`、
   `src/dev`，且 `core/ps` 行没列 `vendor` / `common-use`。已补齐（体检第 6 项从「不通过」转「通过」）。
4. **勾选 / 单选的焦点不可见**：原生 input 是 1px 透明，键盘 Tab 过去看不到落点。

   页面不许 import `core/ps`（页面零底层），但按钮配置需要这个联合类型——不转出去，M2 必然在页面里
   抄一份 `'左右' | ...`。
8. **`reorder` 队列内长度守卫**：`commands/common-use.ts:172`。两次读之间文件被改过时，

9. **通道口径文档纠错**（用户复核提出）：`CONVENTIONS` §4.7 把 `cy_distributedByPitch` 写在直调行，

   补上这个例外、§11.4 第 1 条补「两处都是调度」。代码暂不动，见 P1 第 7 条。

### 7.3 查过但确认「不是影子」的

- `ps_onJsx` 字面量只剩 `core/ps/vendor.ts` 一处；`evalScript/callJsx`、`fetch`、`split('|')` 在允许层之外为 0。
- `EYEDROPPER_TIMEOUT = 60_000`（`commands/style.ts:266`）与 `WRITE_TIMEOUT` 同值但语义不同
  （等用户吸色 vs 写操作超时），**不算重复常量**，保留各自命名。
- `4096` 在 `domain/image-color.ts`（采样档位）与 `domain/style-library.ts`（渐变刻度）指的不是同一件事。
- **两处数值 `clamp` 没有合并**（`features/font-panel/NumberField` 与 `hooks/floating-position`）：
  前者是「可选的上下限」，后者是 `Math.min(Math.max(v,min), Math.max(min,max))`——
  视口比浮层还小时要靠它把上界抬到下界之上。合成一个会改掉浮层的退化行为，属语义不同，不合并。
- `core/auth` 的 `localStorage`：已按「token 是凭证，不进界面偏好文件」写进 `CONVENTIONS` §4.8 的例外，
  不再是偏离。
