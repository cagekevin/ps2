## 4. 风险清单

### P1（看得见的缺陷）

**4.1 字体管理页筛选 chip 没有任何样式**

- 用：`features/font-manage/components/FilterPanel.tsx:39`、`:49`（`mm-font__filter-chip` / `--on`）
- 有：`FontManagePage.css:33` 只有容器 `.mm-font__filter-chips`（复数）
- 后果：chip 无高度 / 圆角 / 间距 / `cursor` / 选中蓝；「全部」与各标签是一排裸文字，点没点中看不出来。
- 同时违反 §6.1：裸 `<button>` 未挂公共壳（`.mm-btn`）。
- 处理：**当日已补**（`FontManagePage.css`）：容器加 `gap`，组与标题补间距 / 字号，chip 补高度（`--mm-tag-strip-h`）/ 左右内边距 / 圆角 / 字号 / `cursor`。
- **选中态不用 accent**（用户 2026-10-30 定）：反白（底 `--mm-color-text-popover` + 字 `--mm-color-bg-popover`），只消费浮层那两个 token，不新增色值。
- **刻意不挂 `.mm-btn`**：筛选面板在浅色浮层里（规则 16），`.mm-btn` 的文字色与 hover 底是页面表面的深色值，落在白底上会变灰字 / 黑块。浮层版按钮表面属视觉重写范围，届时由 `.mm-btn` 变体统一给 —— 这一条是 `TD-09-12` 保留的那半。

### P2（结构小问题，可延后）

**4.2 65 个 token 零引用**（`tokens.css` 172 个变量里）

- 集中在色值段：`--mm-color-bg-card` / `bg-tabsbar` / `bg-editor` / `bg-font-card` / `bg-disabled` / `mask*` / `hover-1|2` / `layer-1..7` / `ok` / `warn` / `accent-soft` / `accent-solid` 等。

- 风险：下一个写样式的人从 token 表里挑一个「看起来对」的变量，其实没有任何一处消费，改它不生效。
- 处理：登记 `TD-11-2`，视觉定稿后按引用清一遍（不许在视觉轮之前清，否则重写时又要加回来）。

**4.3 121 个类名在 css 里零规则**（按文件：font-panel 34 / font-manage 22 / style 11 / common 8 / components 20 / 其它 26）

**4.4 隐藏 input 的规则放在 `global.css`**

`.mm-check__input` / `.mm-radio__input` 的 `position: absolute; opacity: 0` 在 `global.css:149`，而这两个类的其余规则（`:checked +` 兄弟选择器）在 `check-box.css` / `radio-button.css`。同一组件的规则分两个文件，改尺寸时容易只改一处。不冲突，属位置问题。

**4.5 `--mm-swatch` 两种写法**

`StylePage.css:136` 是 `var(--mm-swatch)`（无兜底），`FontPanelPage.css:49` 是 `var(--mm-swatch, var(--mm-color-bg-input))`（有兜底）。该变量由 TSX 注入（`ItemView.tsx:119` / `FontColor.tsx:145`，§14.1 授权），两处语义一样，写法应统一。

## 7. 复现方法（脚本已删，按此重写）

1. 硬编码 / px / `!important` / 时长：`rg -n '#[0-9a-fA-F]{3,8}\b|rgba?\(|hsla?\(|[0-9]+px|!important' src --glob '*.css'`，逐条看是否在注释里。
2. 变量对账：扫所有 css，`/(--mm-[\w-]+)\s*:/g` 得定义集、`/var\((--mm-[\w-]+)/g` 得使用集，两侧差集即 §4.2；注意排除 JS 注入的两个（`--mm-swatch` / `--mm-select-panel-w`）。
3. 类名对账：css 侧 `/\.(mm-[\w-]+)/g`，tsx 侧 `/(?<!-)\b(mm-[a-z0-9_-]+)/g`，差集即 §4.3；再对「css 有、tsx 无」做一次，命中里排除 `${}` 模板拼接。
4. 孤儿 css：把每个 css 的文件名拿到 ts/tsx 的 `import '...css'` 里对。
