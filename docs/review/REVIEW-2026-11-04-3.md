## 一、总体结论

七项全过，其中第 2 项（重复实现）**当场发现并修掉 1 处**：`commands/common-use.ts` 里新写的 `dirOf`
与 `core/storage/index.ts:119` 的 `dirnameOf` 是同一件事的两份实现。已删本地副本、改为引用 `dirnameOf`
（`core/paths` 不能放：它 import 了 `storage` 的 `ROOTS`，反向 import 成环）。
