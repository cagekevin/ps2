## 3. 风险清单

### P0（只能真机关闭）

1. **`VENDOR_FUNCS` 60 项一次性探测**：`src/core/ps/init.ts:81-107`。
   缺一个就整片 vendor 不可用，会同时打掉**已交付**的字体面板与样式页。
   真机首验只做这一件事；缺失的处理是从探针里移除该名（不是页面兜底），并同步
   `PS-CHANNEL-NOTES` §11.4 与 `GOVERNANCE` 4.1。

### P1

2. **`cy_getImagePath` / `cy_getPsdForFolder` 只登记不接线**（`core/ps/common-use.ts` 末尾）：
   v2 的嵌入图片 / 导入多图片才用，返回结构未实测，现在 `Result<unknown>` 原样透出。
3. **`reorder` 读两次盘**：`commands/common-use.ts` 先读一次校验下标、队列里再读一次。
   已加「队列内长度守卫」（数量变了就不写），正确性有保障，多一次读是可接受成本。
4. **7 个格子灰态**（嵌入图片 / 嵌入多图片 / 导入多图片 / 自动填充颜色 / 优化文档 / 自定义变换 / 导出图片）：
   v1 没有对应命令，宁可是灰的也不给「点了没反应」的按钮。v2 接线后自动变可点。
5. **子面板参数不落盘**：间距默认 10、安全区宽度默认 20，关面板即回初值——这是原版行为
   （`mode` / `width` 是组件 data）。要记住得进 `sj_set.json`，属新行为，没自作主张加。
6. **`features/style/useStyleActions.ts:111` 用 effect 重置展开态**（react-best-practices
   `rerender-derived-state-no-effect`）：该在切仓库 / 切 tab 的事件里做。属已交付页面行为，
   改它要真机看展开态，未动。
