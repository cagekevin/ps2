## 1. A3 → 不一致（三层手势模型不同）

**官方实况**（`app.v4.js`，三层手势 = **左键 / 右键 / Ctrl+右键**）：

| 手势 | 官方行为 | 出处 |
|---|---|---|
| **左键**（瓦片主体） | 有命令→执行；`自定义变换/参考线/按间距分布`→`case 22: n.open(e)` 展开**内联面板** | `clickFunction` @1281928；瓦片绑定 @1211876 |
| **右键**（瓦片主体，无 Ctrl） | **无动作**（no-op） | `fpFunction` `case 0` → `case 37` 直接结束 |
| **Ctrl/Cmd + 右键** | **自由面板** `$freePanelBox.show(名称, jsx函数, 参数)` | `fpFunction` `case 36` @1271646 |
| 「更多」子元素右键 | `open(a)` 展开内联面板 | @1213005 |

关键判据在 `fpFunction` 第一行——`ft.f()` 就是通用修饰键函数（@2267897）：

```2267897:docs/原版/app.v4.js
function o(t) { try { return window.event.ctrlKey || window.event.metaKey; } catch (e) { return false; } }
```

```1271646:docs/原版/app.v4.js
fpFunction: function (t, e) { ... case 0: if (!Object(ft.f)()) { e.next = 37; break; }
  ... case 36: n.$freePanelBox.show(t.name, a, i); case 37: case "end": return e.stop(); }
fpTransformPosition: function (t) { if (Object(ft.f)()) { this.$freePanelBox.show(t, "cy_transformPosition", t); } },
fpZoom: function (t) { if (Object(ft.f)()) { this.$freePanelBox.show(t, "cy_zoom", t); } },
```

**常用页所有自由面板入口都要求按住 Ctrl/Cmd**（瓦片 `fpFunction`、缩放档位 `fpZoom`、变换 `fpTransformPosition`、间距排序 `fpSpacingDistribution` —— 后三个绑定在 `click:执行 / contextmenu:自由面板` 上，语义一致）。

**官方自由面板 10 个入口**（`$freePanelBox.show` 全部调用点）：
`批量优化文档`(cy_batchOptimizeDoc @1222304)、`生成变换`(zdy_customBuildTransform @1232060)、`导出一级图片`(cy_batchExportLayer @1248222)、`导出二级图片`(cy_batchExportSecondLayer @1247646)、`批量导出文件夹PSD`(cy_bacthExportPsdToImage @1247347)、`打开所在目录`(cy_exportOpenFolder @1248386)、`合并矩形`(zdy_mergeRectangles @1197781)、`生成框架`(zdy_generate @1198045)、`元素变换`(cy_transformPosition)、`元素缩放`(cy_zoom)。

**我方实况**：
- 左键：有命令→执行，只有面板→展开内联面板 ✓ **与官方一致**；
- 右键：`IconPanel.onContextMenu`（`src/components/IconPanel/index.tsx:244-248`）→ `toggle(id)` **切换**展开内联面板，**无 ctrlKey 判据**。官方瓦片主体右键是 no-op（官方把「展开」放在左键、「更多」子元素右键才展开）→ 我方**多了一个手势**（不构成缺失）；
- **Ctrl+右键 → 自由面板：完全没有**。`moreId` 只在 `src/domain/common-use.ts:270` 被复制进 item、无任何组件消费（全仓搜 `moreId` 无渲染处）→「更多」按钮也没实现。

**结论**：A3 **不一致**——缺的是「**Ctrl+右键 → 自由面板**」整层（低频动作，影响面小但确实缺失）。另需纠正任务书两处表述：①「右键展开」只在「更多」子元素成立，瓦片主体右键无动作；②「Ctrl+**点击**进自由面板」应为「Ctrl+**右键**」（官方 `fp*` 全挂在 `contextmenu` 上，`clickFunction` 无修饰键分支）。
（另注：字体面板也有「Ctrl+点击加入自由面板」语义，我方实现于**动作页** `src/features/action/ActionPage.tsx:104` → `notifyFreePanel()`，字体面板 v1 只提示「未上线」 `src/domain/free-panel.ts:4`——那是**另一个页面**的同名机制，与常用页无关。）

## 2. B3 → 不一致（缺自定义缩放输入框）

**官方实况**：
- 档位按钮：`click: changeSize(e)`，`changeSize(t)` = `e.$cep.jsx("cy_zoom", [t], "自由变换")`（@1289085）——**数字直传 jsx，无非法值拦截**。
- **自定义倍数输入框（官方确实能输倍数）**：绑定 `enlargeVal`（放大）/ `narrowVal`（缩小），渲染 @1205974：

```1205974:docs/原版/app.v4.js
nativeOn: {
  keyup: function (e) {
    if (!e.type.indexOf("key") && t._k(e.keyCode, "enter", 13, e.key, "Enter")) {
      return null;                        // ← Enter 被显式排除
    } else {
      return t.inputSize(t.enlargeVal);   // ← 其余按键即时应用
    }
  },
  contextmenu: function (e) { e.preventDefault(); return t.enlargeOpen.apply(null, arguments); }
},
model: { value: t.enlargeVal, callback: function (e) { t.enlargeVal = e; }, expression: "enlargeVal" }
```

  即 **`keyup` 绑定 + Enter 显式排除**：非 Enter 的按键（含数字键、退格）走 `inputSize(t)` = `t.replace(/[^\d]/g,"")`（剔非数字）→ `changeSize(t)` → `jsx("cy_zoom",[t])` **即时应用**。
- 输入框**右键** = 自由面板 `enlargeOpen`；档位按钮**右键** = `fpZoom` → `freePanelBox.show(..., "cy_zoom", t)`。
- 官方**没有任何缩放中文校验句**（`倍数` 全仓 0 命中）——它靠「剔非数字」而非「提示」保证输入合法；空串由 `changeSize` 交给 jsx。

**我方实况**：`ZoomRow` 只有预设档位 + 「all」列表（`enlargeAll`/`narrowAll`），**无自由输入框**；档位按钮右键 = 展开「整体放大/缩小」列表；`zoom()` 多了「请输入有效的缩放倍数」拦截（**我方自加防护，官方没有**）。

**附带纠正（两处）**：
1. 任务书写「输入框 **Enter 直接应用**」——与官方**相反**。官方 `keyup` 里 Enter 被 `return null` **排除**，恰恰是**非 Enter 才应用**。
2. `daily/架构日志/04-跨区-常用页失败文案审计-2026-10-29.md` §5.5 判「请输入有效的缩放倍数」**当前不可达**（因我方只有预设档位）、§6#6 判「官方缩放无输入校验句 ⇒ 该句无官方原话可抄」——两处结论**都成立但需补一句前提**：官方**有**倍数输入框，只是它的校验方式是「剔非数字」而非「弹中文提示」。补上输入框后，我方那句拦截就**变可达**，且它仍是自造句（官方无对应中文），收口方案里应按「输入校验单列」处理。
