## 1. 总体结论

**不乱。** 四类曾经「有两个出处」的东西本轮收成一处：

| 能力 | 现在唯一出处 | 旧出处 |
|---|---|---|
| 输入位表面（底色 / 描边 / 圆角 / 文字色 / 字号） | `ui.css` 的 `.mm-input, .mm-field-surface` | `.mm-input` / `.mm-select-box__trigger` / `.mm-font-panel__number-box` 各一份 |
| 输入框底色 | `tokens.css` 的 `--mm-color-bg-input`（1 处定义、1 处使用） | — |
| 勾选 / 单选收缩规则 | `global.css` 的 `.mm-check, .mm-radio` | 两个组件各一份 |
| 折叠区间距 | 容器 `gap` | `Collapse` 自带 `margin: 12 0` |
| 遮罩 | `--mm-color-mask` + `.mm-modal-mask` | `Loading` 用 8% 白、`Spin` 用页面底色、标签弹窗自绘一份 |

问题全部在**文档侧**，而且集中在 `CONVENTIONS` §7 与 §6。
