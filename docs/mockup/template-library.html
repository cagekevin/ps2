模板库

一个简单的模板库：存、找、看、置入、整理

界面只放影响决策的信息：找得到、看得清、能置入、能整理。没问题的时候界面不说话：空态与失败态就地显示，不常驻一行状态话。

新建文件夹（线上有这个能力，但没有可见入口）

  • 三个入口同一个动作：左栏标题右侧的「+」、左栏底部常驻的「+ 新建文件夹」、右键某个文件夹里的「在此新建子文件夹」。
  • 抽屉里只有两样：名称 + 建在哪一层（默认当前所在层）。同级重名当场拦下；创建后自动展开父级、新文件夹出现在树里并可直接拖模板进去。
  • 右键文件夹可重命名、删除；只有空文件夹能删，非空时菜单项置灰并说明原因。不建回收站。

长名字

所有名称（卡片、面包屑、文件夹树、文件夹条、检查器、大图、移动列表）一律单行 + 尾部省略号，鼠标悬停用 title 看全名。名字再长也不撑高卡片、不挤歪两栏、不让面包屑换行。假数据里放了三条超长名字，可直接看效果。

落地边界（给下一个 AI）

  • 条目仍是 TemplateItem：id / file / ext / name / folderId / width / height / createdAt。列表固定按存入顺序（新在前），不提供排序控件。
  • 五个 PS 能力不变（存入 / 更新预览图 / 置入 / 编辑源文件 / 打开库目录）；只改「什么时候触发、触发前给用户看什么」。
  • 页面只调 commands/template.ts，写索引只走 repo 的读改写入口；UI 件走 components/ui 与 STYLE.md §6.2；本稿色值只是方向，落地换回 tokens.css。
  • 面板宽度下限 300。宽档三栏、中档检查器降为底部抽屉、300 档侧栏折成下拉；不设计 300 以下。
