## 1. 范围

### 1.1 v1（本计划做）

| 块 | 内容 |
|---|---|
| 根页面 | 顶部 6 图标（3+3，带角标位）+ 底部 4 组 12 个对齐图标；面板互斥；分布输入弹窗 |
| 9 个组件 | 翻译 / 拆分 / 生成按钮 / 粘贴文字属性 / 字体快选 / 层级字号 / 字体属性 / 分布弹窗 / 根 |
| 修饰键 | **Shift**：点文本 / 段落对齐切换；**Ctrl**：v1 只留角标与提示，不接自由面板（见 §1.2） |
| 数据 | 设置写 `sj_set.json` 的 `zt*` 字段；快捷字体 / 层级 / 翻译计数 / 最近字体各一个 JSON |
| 命令 | 20 条 `font-set.*`，全部在 `commands/`，页面零 jsx |
| 文案 | 36 条主文案 + 各子面板档位，逐条对齐参考文档第四节 |

### 1.2 明确不做（不是漏）

| 项 | 原因 |
|---|---|
| 自由面板（Ctrl+点击加入、`sj_appFreePanel.json`） | 需要先有自由面板整页；本页只做「Ctrl 点击 → 提示未上线」，不写半套 |
| 层级预设云同步 | 原版 `$sync.pushFile`；服务端协议未定，v1 只写本地 |
| 智能排版 / 排版强度 | 原版 Vue 已整块移除，不复活 |
| 字体缺失「前往下载」确认框（T-43） | **永久不做，任何版本都不做**：不弹确认框、不给外链；缺字体只 toast「字体不可用」 |
| 属性面板的历史 / 分类 / 星级 / 中文/英文分组 / 预览档位 | Vue 的增强，不属于原版核心；v1 只做「当前字体 + 字重 + 颜色 + 字号/行距/字距 + 4 开关 + 3 向对齐」 |
| 拆分 / 生成按钮的**右键**加入自由面板（T-40） | Vue 也没做；且自由面板整页未立项 |
| 全局 Ctrl 点击关闭自由面板选择器 | 原版 `ctrlClickFun` 关闭逻辑，Vue 未做；v1 无自由面板选择器 |
| 自由面板 / 常用页 / 快捷键复用入口 | 命令 id 已按可复用设计，但入口页面不在本计划 |

### 1.3 判定口径

- **9 行组件每一行必须有落点**（见 §4），合并/后续都要写明。
- 视觉用 token + 原版实测值，不逐条抄 111 个 class；`fontset-*` 旧类名不沿用，统一 `mm-font-panel__*`。
- 文档里的 `未确认` 是「视觉没逐条复核」，不等于代码没写；本计划不把 `未确认` 当已完成。

**四条命令的内部流程（照这个顺序实现）**

- `copyFont`：`core/ps/font.getFontInfo()` → `setFontClipboard(data)`；失败原样返回，不写剪贴板。

- `split`：先 `changeTextBranchMerge(mode)`（原版用它做前置确认），再 `textBranchMerge(mode)`；两步都失败即失败。
- `applyFontName`：`core/ps/text.setFontName`；`err === 1` → `VALIDATION`「字体不可用」；成功且传了 `family` → 追加 `sj_ztglHistory.json`（最多 10，写失败只记日志）。

### 3.8 数据流与契约归属（这部分也由计划定死）

**单向数据流，没有第二条路：**

```
读：PS jsx (core/ps/text, raw)
      → domain 归一 (text-info / translate / quick-font / font-set)
      → store (text / font-set) 只读投影
      → 页面订阅

写：页面事件
      → commands/font-set（校验 + 编排）
      → core/ps/text（jsx 写） / repo/font-set-repo（文件写）
      → Result 回到命令
      → 页面：失败 toast；成功 patch 本地或 store.refresh()
```

禁止：页面 import `core/ps`、`core/storage`、`core/cep`；store import `commands`；
`domain` 做 IO；`repo` 弹提示；`commands` 直接 `JSON.parse` 文件。

**状态归属（唯一真相）**

| 状态 | 唯一真相 | 内存副本 | 失效/刷新 |
|---|---|---|---|
| 当前文字属性 | PS 文档 | `store/text.info` | 进页面读一次；写成功后 patch；M4 订阅选区事件再 refresh |
| 字体面板设置 | `sj_set.json` | `store/font-set.settings` | 进页面读；改动先本地（`setLocalSettings`），200ms 后 `saveSettings` 落盘 |
| 快捷字体 | `sj_ztQuickFont.json` | `store/font-set.quickFonts` | 命令成功后 `load()` |
| 层级预设 | `sj_ztHierarych.json` | `store/font-set.hierarchy` | 同上 |
| 翻译次数 | `sj_ztTranslate.json` | 不缓存 | 每次翻译命令前读、成功后写 |
| 最近字体 | `sj_ztglHistory.json` | `store/font-set.history` | 应用字体成功后追加（写失败只记日志） |
| 复制板 | 内存模块 | `domain/font-set-clipboard` | 刷新页面即丢（原版同） |
| 面板开关 | 页面本地 state | — | 不落盘 |

**写入顺序（所有命令按这个模板）**

1. 先校验：数值/6 级/1000 字/380 次/剪贴板是否存在；不过就不发 jsx。
2. 先写 PS、后写本地：jsx 失败时**不** patch 本地快照。
3. 文件写只走 repo 的 mutate；写失败返回 `IO_ERROR`，不吞。
4. 翻译：成功后**才**加计数；失败不改文档、不计数。
5. 设置：本地立即生效，落盘失败 toast「设置未保存」，界面保留用户输入（下次启动回落到文件值）。
6. 不自动重试；重试由用户点第二次触发。

**契约冻结（写代码的人不许自行改）**

1. §3.7 的函数名、参数顺序、返回形状**冻结**；要改先改计划并写明原因。
2. 新增公开导出必须登记 `CONVENTIONS` / `GOVERNANCE`；不许在组件里就地定义同名类型。
3. `domain` 类型只定义一次；`components` 不许复制 `interface`，只做 `Pick` / 局部展示类型。
4. 组件 props 可以自行设计，但**不得引入新的 domain 形状**；发现需要，先停下问。
5. 文件名 / 路径只能由 repo 产出；页面和命令不许拼 `sj_*.json` 字面量。
6. 数据流方向不得反转：页面不写文件、store 不调命令、domain 不碰 IO。

| 风险 | 影响 | 处置 |
