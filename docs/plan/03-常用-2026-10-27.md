- 页面零底层：`features/common` 只 import `commands`、`store`、`domain` 类型、`components`。

**写盘之后的刷新与回滚（三条规则，不许各页自己发挥）**

| 命令类型 | 成功后 | 失败后 |
|---|---|---|
| 执行类（zoom / flip / 位置对换 / 替换 / 配色互换 / 修正模糊 / 分布 / 参考线） | 不重读任何文件（页面无状态变化） | `toast.error(reason)`，不改任何本地状态 |
| 数据类（`setShow` / `reorder` / `resetAll`） | `store.load()` 重读一次 | 回滚到写前快照（先备份数组再改）+ `toast.error` |
| 参数类（`setOption`） | 先写盘、成功后 `store.load()` 重读 | **不本地 patch**，保留旧值 + `toast.error`（避免面板显示与文件不一致） |
| 折叠（`setCollapsed`） | 同步写 prefs，立即生效 | prefs 写失败只记日志（偏好不是业务数据） |

> 「乐观更新」在本页只用于折叠态。其余三类都走「先写盘、成功再刷新」——
> 网格顺序/显隐是用户能一眼看出来的东西，先动 UI 再失败回滚会闪。

## 5. 页面结构与交互

```
CommonPage
├─ 区域一：缩放（cyShowZoom）
│   ├─ 顶部：放大 / 缩小 两个**输入框**（左侧图标；点右侧或右键开预设档位；Enter 直接应用）
│   ├─ 放大 4 档 / 缩小 4 档（26 高小按钮）
│   └─ 整体放大 10 档 / 整体缩小 10 档（十颗 `calc(20% - 4.8px)`）
├─ 区域二：变换（cyShowTransformation）
│   └─ 翻转 6 向
├─ 分隔线
├─ 网格：14 项 × 3 列（拖拽排序；`isMore` 项左键/右键都展开子面板，普通项左键直接执行）
│   ├─ 每行一个 `<IconPanelGroup exclusive openId={expandedId}>` —— 全局只开一个
│   │   面板落在**该行之后**（与原版 `splice(n*3+3, …)` 一致），不是浮层、不是页面底部
│   └─ `comName` → 面板组件：`comreference` / `comspacing`（v1），其余 5 个 v2
└─ 折叠条（折叠态存 prefs）
```

交互约束：
- **点击 `isMore` 的项 = 展开子面板**；点击普通项 = 执行命令；两者都不改排序。
- 拖拽排序用指针事件，**不用全局 `event`**（原版 `drag()` 用了未声明的全局 `event`，是缺陷，不照抄）。
- 折叠态与显隐开关**是两个概念**：折叠是本地偏好，显隐写 `sj_set.json`。
- 子面板一次只开一个（`IconPanelGroup exclusive`）。

## 8. 风险与回滚

| 风险 | 影响 | 处理 |
|---|---|---|
| `cy_swapWireframeFill` / `cy_useGride` 是派发表 key 不是函数 | 缺函数 → 整页判未就绪 | M1 第一步核准；核不到就不登记，命令层同步删 |
| 官方 14 项种子里有我们没见过的键（`sort` / `openistrue`） | 写回时丢键 → 官方面板读不到 | `CommonUseItem` 带索引签名，**未知键原样保留** |
| 拖拽排序与官方下标算法不同 | 顺序错位 | 复用 `domain/reorder` 的落点计算，不自己算 |
| 「整体放大」档位含 `101` 这种极小值 | 视觉效果不明显，误判为无效 | 真机逐个点一遍，异常档位在 §4.1 标注 |
| 折叠态写 prefs、显隐写 `sj_set` | 用户以为是一件事 | UI 上分开：折叠是箭头，显隐在设置页 |
| **24 个 `$appBus` 事件**（清单 §八-2）本该都落成命令 | 外部面板 / 快捷键触发时没有入口，或页面里私接 bus | v1 只接与已做按钮对应的；其余与 v2 子面板同批。**禁止在页面里直接订阅 bus**，一律走 commands |
| 折叠态与官方 `sj_v5_ui.json` 不同步 | 换回官方面板时折叠丢失 | 明确不承诺同步（我们只用 prefs），写进本页文件头 |
| **官方同一件在不同位置给了不同值**（功能格 50 vs 32、分隔线 100% vs inset 30、小图标按钮两套） | 抄错就与其它页不一致 | 本页一律取 **scoped 值**（§4.1 表），不取平均、不借全局值；写码时按表取，不凭记忆 |

**回滚**：本页是纯增量（新页面 + 新文件）。若 M2 中止，删 `features/common` 并把
`nav-config` 的 `implemented` 改回 `false`；`commands` / `repo` 未被其他页面引用，一并删。
