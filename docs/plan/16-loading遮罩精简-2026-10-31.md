# 16 · loading 全屏遮罩精简

**日期**：2026-10-31
**依据**：官方 `docs/原版/app.v4.js` 的 `$load` 用法 + 我们自己的代码现状
**结论**：遮罩只保留给「单次耗时 > 1 秒」的操作；秒级内的操作当前误加了遮罩，计划全部去掉。

---

## 一、规则

- 我们已有同款基础设施：`core/feedback/loading`（`show/hide/run` = 官方 `$load`）、`components/Loading`（全屏遮罩）、`components/Spin`（转圈）。**不新建任何东西**。
- `useRunCommand` 默认 `spin: true` 弹遮罩；传 `{ spin: false }` 不弹。
- 命令层 `loading.show/hide` 只用于**批量/跨文档循环**的逐文件进度（官方 `正在导出: X/Y` 写法）。
- **唯一判据：单次操作预计 > 1 秒才弹遮罩。秒级内的，弹了也没意义，去掉。**
- 官方 50 处 `$load` 里既有真慢的（循环 / 网络），也有加多了的（开关、写库、甚至把警告当 loading）。我们只对我们**真做了且真慢**的功能保留。

## 五、落地方式

1. **默认即遮罩**：`useRunCommand` 默认 `spin: true` 保持不变（慢操作不漏）。
2. **删除项统一加 `{ spin: false }`**：
   - 直接调 `run(task, { spin: false, ... })` 即可。
3. **`useStyleActions` 的两个封装不透传 spin**：`runWithToast` / `runWithFeedback` 目前只拼 `STYLE_RUN`，不接收 `spin`。两种改法二选一：
   - 给两个 helper 加一个 `spin` 出口（默认 `true`），调用处按需传 `false`；
   - 或把第四章里 style 页那几个 CRUD 调用改成直接 `run(task, { spin: false, success, after })`。
4. **`onPasteFont`**：改 `loading.run(task, { spin: false, tip: '正在应用字体设置' })`，或统一走 `runCommand(task, { spin: false })`。
5. **`useCommonPage.activate`**：按 tile id 分流，`correctBlur/swapWireframeFill/exchangeLayerColor` 传 `{ spin: false }`，其余保持默认。
