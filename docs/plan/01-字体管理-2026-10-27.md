## 3. 数据契约

### 3.1 文件（均在 `legacy` 根 = `%APPDATA%\SheJiZhuLi`）

| 文件 | 读/写 | 用途 | 形状 |
|---|---|---|---|

| `classification.json` | 只读 | 只取语言分组 | `{ categories: {...} }`；`presets` / `commercials` 不解码（无消费点） |

### 3.2 两套键名（不能混）

| 场景 | 键名 |
|---|---|
| jsx 返回 / 页面使用 | `family` / `weights` / `names` / `postScriptNames` |
| 磁盘缓存 `SysFont2.json` | `name` / `zz` / `mz` / `hjm` |

归一化唯一入口：`domain/font-normalize.ts`。签名固定为：

```ts
normalizeFontItem(raw: unknown): Result<FontItem>
normalizeFontList(raw: unknown): { list: FontItem[]; dropped: number }
```

`dropped > 0` 必须进 UI（计数行一句「N 个字体项无法识别」），**不允许只写日志**（`CONVENTIONS` §4.2）。

### 3.3 通道与超时

| 调用 | 通道 | 超时 |
|---|---|---|
| `ztgl_initSystemList` | **直调** `jsx()`，不是 `ps_onJsx` | 新增 `LONG_TIMEOUT = 300_000` |
| `ztgl_setFont` | **直调** `jsx()` | `WRITE_TIMEOUT = 60_000`（已有） |

`vendor.jsx` 与 Vue 版 `all.decrypted.js` 逐字节相同（338,105 字节），因此两个函数一定存在，不需要写新 jsx；只需在 `VENDOR_FUNCS` 登记，否则会被误判为缺能力。

> `core/ps/font.ts` 只返回**原始字符串**（`Result<string>` / `Result<void>`），**不能 import `domain/`**（依赖表禁止）。归一化在 `commands/font.ts` 做。
