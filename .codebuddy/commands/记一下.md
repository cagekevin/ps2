# 记一下

> 一句话：**一份状态只写一处**。动手前先认领落点，别在几处各记一遍（几处都记 = 迟早不一致）。

1. **做了什么 / 踩了什么坑** → `docs/CHANGELOG.md`（一篇一文件，文件名带日期，平铺）
   - 新建：追加到 `docs/CHANGELOG.md`（一篇一文件，文件名带日期，平铺；模板含「背景 / 做了什么 / 结论」）
   - 重建索引：本仓暂无 log 工具，索引人工维护（`docs/CHANGELOG.md` 不单独维护 index 产物）。
   - 只在**决策 / 踩坑 / 架构变更**时写；日常改动不写。
2. **决策与判据** → `docs/adr/`：`node scripts/adr.mjs add --title "…" --conclusion "…" --user-approved`
   （一条一文件；索引由 `node scripts/adr.mjs index --write` 生成，**禁手改**；六问答卷由 AI 贴给用户看、**由用户拍板**）
3. **区域过程 / 轮次** → `daily/架构日志/<NN>-<区域>-<YYYY-MM-DD>.md`（债的锚点写这里）
4. **待办 / 债** → `daily/架构日志/债务.md`（**唯一写入口 = `node scripts/debt.mjs`**）
   - 登记：`node scripts/debt.mjs add --area NN --summary "…" --anchor "<区域日志文件名>"`
   - 改状态：`node scripts/debt.mjs resolve <TD-ID> --status 已解决 --note "…"`（**就地改，不追行**）
   - 体检：`node scripts/debt.mjs list`（`check` 仍在，但**不再进 `npm run check`**：手写文档不作门禁）
5. **任务** → `daily/架构日志/00-任务-总索引.md`（`T-xx`，手改这个文件；代码里 `TODO(T-xx)` 靠人核（原 `ledger` 闸已删））
6. **页面状态** → `docs/CHANGELOG.md`（每页做到哪、缺什么）；**页面验收** → `docs/plan/`（线上 PS 应用 vs 我方逐项）

> 落点不确定时，先看仓库根 `AGENTS.md` 的「文档分工」表与 `docs/GOVERNANCE.md`。
> 本仓分层见 `docs/CONVENTIONS.md` §3（依赖方向表 + 目录树是唯一真源，本文件不复述）。
